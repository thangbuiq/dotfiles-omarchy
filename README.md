# dotfiles-omarchy

Catppuccin Mocha setup for Omarchy (Arch + Hyprland): Hyprland bindings, Omarchy shell and custom bar plugins,
Vicinae, Superwhisper, fontconfig (Inter), Neovim, tmux, terminals, Chrome flags and the Claude Code statusline.

Paste this into Claude Code on the new machine:

```text
Set up my Omarchy desktop from my dotfiles-omarchy repo. Clone it to ~/dotfiles-omarchy (skip if it exists),
read AGENTS.md fully, follow its Setup procedure step by step, hand me the manual steps, then run its
Verify commands and report what passed or failed. Do not commit or push, and ask before overwriting existing config.
```

To sync this machine's live config back into the repo, run `/update-dotfiles` in Claude Code from the repo (manual only).
